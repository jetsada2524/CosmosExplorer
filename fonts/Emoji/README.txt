CosmosEmoji.ttf   = subset of Noto Color Emoji (SIL OFL 1.1, Google) - SVG glyphs only, characters used by the game
CosmosSymbols.ttf = subset of DejaVu Sans Bold (Bitstream Vera / public domain license) - arrows & symbols
Used as font fallbacks (see UITheme._setup_font_fallbacks) so the Web export, which has no system fonts, renders Thai/emoji.
