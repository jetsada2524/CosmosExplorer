# Cosmos Explorer — เอกสารออกแบบเกม (Game Design Document)

> เกม 3D มุมมองห้องนักบิน ให้เด็กบังคับยานอวกาศเดินทางจากโลกไปยังดาวเป้าหมาย หลบอุกกาบาตและอุปสรรคในอวกาศ เก็บไอเทม ตอบควิซ และเรียนรู้ข้อมูลจริงของดาวเคราะห์ในระบบสุริยะ

- **เวอร์ชันเอกสาร:** 1.0 (จัดทำจากโค้ดที่มีอยู่จริง)
- **วันที่:** 29 ก.ค. 2026
- **Engine:** Godot 4.7 (Forward Plus) — โปรเจกต์มีอยู่แล้วและทำงานได้
- **ความละเอียด:** 1920×1080 (16:9) · โหมด Fullscreen · stretch = canvas_items
- **อินพุต:** จอสัมผัส 3 โซน (ซ้าย = เลี้ยวซ้าย / กลาง = Boost / ขวา = เลี้ยวขวา) · ทดสอบบน PC ด้วย A/D + Space
- **กลุ่มเป้าหมาย:** เด็กและครอบครัว · เล่นครั้งละ 1 คน · ออกแบบสำหรับงานนิทรรศการ
- **แนวเกม:** 3D Cockpit Runner / Obstacle Dodger + edutainment (ดาราศาสตร์และระบบสุริยะ)

---

## 1. วิสัยทัศน์ (Vision)

Cosmos Explorer พาเด็กขึ้นยานอวกาศจริงๆ — นั่งในห้องนักบิน มองออกไปเห็นอวกาศเบื้องหน้า แล้วบังคับยานฝ่าดงอุกกาบาตไปให้ถึงดาวเป้าหมาย ยิ่งดาวไกล ยิ่งใช้เวลานาน ยิ่งอันตราย เมื่อไปถึงจะได้ลงจอดและเรียนรู้ข้อมูลจริงของดาวดวงนั้น

หัวใจของเกมคือ 3 คำ: **บิน (Fly) → หลบ (Dodge) → ค้นพบ (Discover)**

---

## 2. Core Gameplay Loop

1. **Attract Mode** — เมื่อไม่มีคนเล่น จอแสดงโหมดดึงดูดเชิญชวนผู้เข้าชม
2. **Login + เลือกอวตาร** — ใส่ชื่อผู้เล่น เลือกยาน (จรวด / ยูเอฟโอ / ดาว)
3. **วิธีเล่น (How to Play)** — สอนการควบคุม 3 โซนสัมผัส
4. **Galaxy Map** — เลือกดาวเป้าหมายจาก 10 ดวง (แต่ละดวงบอกระดับความยากและเวลา)
5. **นับถอยหลัง → บิน** — มุมมองห้องนักบิน 3D ยานพุ่งไปข้างหน้าอัตโนมัติ ผู้เล่นบังคับซ้าย-ขวาและ Boost
6. **หลบอุปสรรค + เก็บไอเทม** — หลบอุกกาบาต/ดาวหาง/เศษยาน · เก็บพลังงาน โล่ คะแนน และกล่องควิซ
7. **ตอบควิซ** — เก็บกล่องควิซแล้วเกมหยุด ถามคำถามดาราศาสตร์ ตอบถูกได้รางวัล + เกร็ดความรู้
8. **ถึงดาว → ลงจอด (Landing)** — แสดงข้อมูลจริงของดาว และให้ดาวคะแนน 1–3 ดวงตามเวลาที่ใช้
9. **Leaderboard** — บันทึกคะแนนขึ้นตารางอันดับ → กลับสู่ Attract Mode

**พารามิเตอร์ความยากต่อดาว** (ปรับได้ในไฟล์ JSON โดยไม่ต้องแก้โค้ด):
`spawn_rate` (ความถี่การเกิดอุปสรรค) · `obstacle_speed_mult` (ตัวคูณความเร็ว) · `max_obstacles` (จำนวนสูงสุดพร้อมกัน) · `star_rating_time` (เกณฑ์เวลาให้ดาว 3/2/1)

### 3.2 อุปสรรค 5 ชนิด (`scenes/obstacles/`)
- **Asteroid (ดาวเคราะห์น้อย)** — ก้อนหินขนาดใหญ่ เคลื่อนที่ตรง
- **Comet (ดาวหาง)** — เร็ว มีหางน้ำแข็ง
- **Meteor (อุกกาบาต)** — พุ่งเข้าหาเร็วมาก
- **Space Debris (เศษยานอวกาศ)** — ชิ้นส่วนโลหะ รูปทรงไม่แน่นอน
- **Stardust Cloud (กลุ่มฝุ่นดาว)** — บดบังการมองเห็นชั่วคราว

### 3.3 ไอเทม 4 ชนิด (`scenes/powerups/`)
- **Energy (พลังงาน)** — เติมพลังงานยาน
- **Shield (โล่)** — ป้องกันการชน 1 ครั้ง
- **Score (คะแนน)** — เพิ่มคะแนนทันที
- **Quiz (กล่องควิซ)** — เปิดคำถามดาราศาสตร์ ตอบถูกได้รางวัล

### 3.4 ระบบควิซ + เกร็ดความรู้ (`data/quiz_questions.json`)
- **คำถาม 10 ข้อ** แบบ 4 ตัวเลือก พร้อม **fun_fact** เฉลยความรู้หลังตอบ
  - ตัวอย่าง: *"ดาวเคราะห์ใดใหญ่ที่สุดในระบบสุริยะ?"* → ดาวพฤหัสบดี — *"ใหญ่กว่าโลก 1,321 เท่า ใส่โลกได้กว่า 1,000 โลก!"*
- **Science Tips 13 ข้อ** แสดงระหว่างโหลด/เล่น
  - ตัวอย่าง: *"อุกกาบาตเคลื่อนที่เร็วกว่าหัวกระสุนปืน 20 เท่า!"*

### 3.5 มุมมองห้องนักบิน 3D (Cockpit View)
- ฉาก `gameplay.tscn` ใช้ `World3D` + `cockpit_3d.gd` เป็นมุมมองบุคคลที่หนึ่ง
- มี **cockpit overlay** (กรอบห้องนักบิน) ซ้อนบนภาพ 3D
- นับถอยหลังก่อนเริ่ม แล้วเปิดปุ่มควบคุม

### 3.6 ระบบอินพุตจอสัมผัส 3 โซน (`touch_input.gd`)
- แบ่งจอเป็น: **ซ้าย = เลี้ยวซ้าย · กลาง = Boost · ขวา = เลี้ยวขวา**
- รองรับคีย์บอร์ดสำหรับทดสอบ: **A / D = เลี้ยว · Space = Boost**

### 3.7 ระบบคะแนน ดาว และ Leaderboard
- ให้ **ดาว 1–3 ดวง** ตามเวลาที่ใช้เทียบกับ `star_rating_time` ของดาวนั้น
- `leaderboard_manager.gd` เก็บอันดับผู้เล่น แสดงในฉาก `leaderboard.tscn`

### 3.8 ฉากทั้งหมดในเกม (10 ฉากหลัก)
`attract` → `login` → `how_to_play` → `planet_select` → `gameplay` → `landing` → `win` / `game_over` → `leaderboard` · และ `admin_settings` สำหรับผู้ดูแลงาน

### 3.9 Autoload (Singleton) 8 ตัว
`UITheme` · `GameManager` · `TouchInput` · `PlanetData` · `QuizManager` · `LeaderboardManager` · `SoundManager` · `GameSettings`

## 4. ไอเดียเสริม เพื่อความตื่นเต้น + ความรู้ (ข้อเสนอเพิ่มเติม)

**ตัวนำทางน่ารัก (Mascot).** น้อง **"คอสโม (Cosmo)"** หุ่นยนต์ผู้ช่วยนักบินตัวจิ๋วบนแผงคอนโซล คอยพากย์ เตือนอันตราย และเล่าเกร็ดความรู้ระหว่างบิน

**เปรียบเทียบระยะทางให้เห็นภาพ.** แสดงระยะทางจริง (เช่น ดาวอังคาร 225 ล้าน กม.) เทียบกับสิ่งที่เด็กเข้าใจ — *"ถ้าขับรถไปดาวอังคาร ต้องขับ 300 ปีไม่หยุดเลย!"*

**สัมผัสแรงโน้มถ่วงจริง.** ตอนลงจอด แสดงว่า *"น้ำหนัก 30 กก. บนโลก = 5 กก. บนดวงจันทร์"* ใช้ค่า `gravity` ที่มีในข้อมูลอยู่แล้ว

**เตือนอุณหภูมิสุดขั้ว.** ก่อนลงจอดแสดงอุณหภูมิจริง — ดาวศุกร์ 464 °C *"ร้อนพอละลายตะกั่ว!"* · พลูโต −225 °C

**สมุดสะสมดาว (Passport).** ไปถึงดาวไหนแล้วได้ตราประทับในสมุดเดินทางอวกาศ กระตุ้นให้เล่นครบ 10 ดวง

**โหมดแข่งเวลา (Time Attack).** ดาวที่เคยผ่านแล้ว เล่นซ้ำเพื่อทำเวลาให้ดีขึ้น ชิงอันดับบน Leaderboard

**เอฟเฟกต์ Boost เร้าใจ.** ตอนกด Boost ให้ดาวรอบข้างยืดเป็นเส้น (warp effect) + จอสั่นเบาๆ + เสียงเร่งเครื่อง

**เหตุการณ์สุ่มระหว่างทาง.** เช่น พายุสุริยะ (จอวูบ ต้องหลบมากขึ้น) หรือ พบดาวหางฮัลเลย์ (โบนัสพิเศษ + ความรู้)

**สรุปการเดินทาง.** หน้าจบแสดง "คุณบินไป 225 ล้านกิโลเมตร หลบอุกกาบาตได้ 47 ก้อน ตอบควิซถูก 3/4 ข้อ"

## 6. ทิศทางศิลป์ (Art Direction)

- **โทนอวกาศจริงจังแต่เป็นมิตร:** พื้นหลังเนบิวลาสีน้ำเงินม่วง มีดาวระยิบ ไม่มืดจนน่ากลัว
- **ห้องนักบิน:** กรอบคอนโซลโค้งมน ปุ่มเรืองแสง จอ HUD โปร่งแสง
- **ดาวเคราะห์:** สีตามจริง (ใช้ `color_hex` ที่มีในข้อมูล) แต่เพิ่มความอิ่มตัวให้สดใส
- **อุปสรรค:** ก้อนหินมีรายละเอียดพื้นผิว (มี PBR texture อยู่แล้วใน `assets/models/`)
- **UI:** ปุ่มใหญ่เหมาะกับจอสัมผัส ตัวอักษรไทยอ่านง่าย
